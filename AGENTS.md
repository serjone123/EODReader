# AGENTS.md — правила работы для ИИ-агентов

Кратко о проекте: Delphi 12 / FireMonkey / Win32, приложение для анализа записей
EOD рыб. Подробности архитектуры, форматы и сборка — в `README.md` (прочитай его
перед началом работы).

## Сборка и проверка

- Сборка — из корня: `cmd /c _build.cmd` (msbuild + rsvars.bat, Debug/Win32).
  Успех = строка вида `NNNN lines, X.XX seconds, ... bytes code` и отсутствие `error`.
- **Запускать приложение и тестировать его руками НЕ нужно** — скомпилировалось,
  значит работа сделана; запуск и проверку делает пользователь. Не трать токены
  на запуск exe, скриншоты, клики по окну, UIA-деревья и т.п.
- Если линкер пишет `F2039 Could not create output file Bin\ReadEOD.exe` —
  у пользователя запущено приложение. НЕ убивай чужой процесс: сообщи пользователю,
  что exe занят, он сам его закроет.
- Известные безвредные предупреждения (не трогать, если не попросили):
  `H2164 PeakPositions`, `W1000 MessageDlg deprecated`, `H2077 BestDistance`,
  `H2219 ShowCurrentRange`.

## Обработчики событий: назначать кодом, а не через форму

Главная ловушка этого проекта. Компоненты из `.fmx` и их события (`OnClick`,
`OnChange`…) связываются через RTTI **published**-секции формы. Если метод-обработчик
оказался в `private`, компилятор молча даёт лишь hint
`H2219: Private symbol '<ИмяОбработчика>' declared but never used` — а форма
**падает при загрузке** (EReadError), причём отловить это компиляцией невозможно.

Правила:

1. **Не полагайся на события в `.fmx`.** Обработчик назначай кодом в `FormCreate`
   (или там, где создаётся компонент):

   ```pascal
   FMyButton.OnClick := MyButtonClick;
   FMyCombo.OnChange := MyComboChange;
   ```

   В `uReadWavMain.FormCreate` это уже устоявшийся паттерн
   (`edStartSample.OnChange := edStartSampleChange;` — с поясняющим комментарием).

2. **Новые нестандартные контролы создавай кодом** (как `FPlayTimer: TTimer`),
   а не правкой `.fmx` — меньше зависимостей от published/RTTI и от дизайнера.
   В `.fmx` добавляй только простые статические вещи (кнопку с `Align/Text`),
   и тогда её обработчик всё равно назначь в `FormCreate`.

3. После любой правки `.fmx` проверь лог компиляции: если у метода-обработчика
   появился `H2219` — событие не привязалось; чини назначением кодом (п. 1),
   а не переносом объявления в published.

## Правила правки файлов

- `uReadWavMain.fmx` — текст ASCII с **CRLF**; переводы строк сохраняй.
  Выравнивание FMX: контролы с `Align = Left` сортируются по `Position.X`,
  т.е. визуальный порядок задаётся координатой X.
- Кодировки исходников различаются: `uReadWavMain.pas` — UTF-8 с BOM;
  `Signal.Peaks.pas` — ANSI/cp1251 (внутри есть битые символы — это нормально,
  не «чинить»); `TODO.md` — cp1251. Файлы не перекодировать.
- Комментарии и UI — на русском языке.
- Не трогай артефакты сборки/IDE (`Bin`, `DCU`, `Win32`, `__history`,
  `__recovery`, `*.identcache`, `*.dproj.local`, `ReadEOD.res`).

## Git

- Не коммитить и не пушить без явной просьбы пользователя.
- `git stash` пересобирает состояние — если использовал stash для экспериментов,
  не забудь `pop` и пересборку после него.

## Здравый смысл по токенам

Цель — минимальная правка, чистая компиляция, отчёт. Диагностику веди по логу
компилятора и чтению кода; «эксперименты» с запуском exe, бинарным grep по exe/dcu
(ресурсы форм там в UTF-16 — обычный grep всё равно ничего не найдёт) и кликами
по GUI не нужны.
