# HISTORY.md — история изменений проекта

Этот файл ведётся всеми разработчиками и ИИ-агентами, работающими над EODReader.

## Правила

Каждая существенная правка должна иметь запись. Особенно обязательно фиксировать изменения, которые:

- меняют логику обнаружения пиков или классификации;
- меняют математические расчёты, фильтрацию, корреляцию, статистику или пороги;
- меняют формат входных/выходных данных или совместимость;
- меняют структуру конвейера обработки;
- исправляют баг, который мог влиять на научный/экспериментальный результат.

Для небольших механических правок достаточно одной строки. Для изменений логики нужна содержательная запись: **что изменено → зачем → что изменилось в поведении/расчётах → как проверено**.

Не переписывать историю предыдущих агентов. Новые записи добавлять сверху, сразу после раздела `## Записи`.

## Записи

### 2026-09-12 — Восстановление позиций пиков в GUI

- В `GUI.Model.pas` восстановлен метод `PeakPositions` для режима `dmPeakFile`.
- Позиции теперь читаются через `TEodPeakStore.ReadRecordInfo`, а не возвращаются пустым массивом из незавершённого lazy-cache кода.
- Добавлена защита от переполнения при преобразовании `PeakCount: Int64` в размер динамического массива.
- Зафиксировано, что публичный метод `PeakCount: Integer` всё ещё требует отдельного пересмотра для полной поддержки очень больших файлов.
- Проверка компиляцией ещё не выполнена: согласно `AGENTS.md`, сборку должен выполнить пользователь.

### 2026-09-12 — Исправление диапазона корреляции

- В `Detection.Correlation.pas` исправлен диапазон перебора позиций шаблона: теперь проверяются все допустимые нулевые позиции `0..N-L`.
- Исправлена инициализация результата для случая, когда лучший кандидат находится в позиции `0`.
- Это устраняет пропуск последнего допустимого окна и делает обработку первой позиции явной.
- Regression test пока не добавлен; он остаётся отдельным пунктом в `TODO.md`.

### 2026-09-12 — Изменения после работы других агентов

- Выполнено переименование модулей: все `.pas` остаются в одной папке, имена отражают подсистемы (`Core.*`, `IO.*`, `Signal.*`, `Detection.*`, `GUI.*`, `Threads.*`).
- `Signal.Peaks.pas`: прежний O(N²) расчёт prominence заменён на два прохода с монотонным стеком, заявленная семантика сохранена.
- `Detection.Detector.pas`: исправлен FIR15 padding с 7 до 8 отсчётов с каждой стороны чанка через `Fir15HalfWidth`; убраны занулённые первый/последний отсчёты каждого блока `ChunkSize`.
- Для новых изменений необходимы regression/golden-тесты: сравнение нового prominence со старой реализацией и проверка корректности FIR15 на границах чанков.
